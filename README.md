## Overview

This repository contains a complete, interactive preparation website for a SIRI clarifying interview regarding a Danish residence and work permit under the Supplementary Pay Limit Scheme.

The guide is designed to help the applicant prepare clear, consistent, and accurate answers based on the submitted documents and employment contract.

### Key Features

- **Bilingual support** — Full English and Bangla (বাংলা) interface with one-click language switch
- **8 question categories** with model answers
- **Searchable questions** — Quickly find topics
- **Interactive checklist** for interview day
- **Key documents overview**
- **Mobile-friendly** design
- **Print-ready** layout
- Clean, professional theme inspired by Danish official design

---

## How to Use

1. Download or open the file `SIRI_Interview_Guide_Pro.html`
2. Open it in any modern browser (Chrome, Safari, Firefox, Edge)
3. Use the language switcher (EN / বাংলা) at the top right
4. Navigate between sections:
   - **Rules** — How to answer questions
   - **Questions** — All expected questions + model answers
   - **Checklist** — Interview day preparation list
   - **Documents** — Important case documents
   - **Final Tips** — What to avoid + what SIRI wants to confirm

> The file works completely offline. No internet connection is required after downloading.
